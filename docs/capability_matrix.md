# Capability Matrix

## Available In MVP

- Contacts read access
- Voice-driven call initiation
- Calendar read access
- Calendar event creation and editing with confirmation
- Reminder creation
- Camera capture and photo upload
- Document upload and AI explanation
- Personal memory storage and recall
- Daily briefing and follow-up prompts

## Near-Term

- Message drafting and assisted sending
- Medication and routine tracking
- Family and caregiver shortcuts
- Navigation and errands assistance
- Better offline cache and queued workflows
- Secure user identity and approvals across devices

## Future Agent Features

- Assistant-to-assistant scheduling
- Shopping agent integration
- Booking agent integration
- Service desk / merchant workflows
- Negotiation over time slots and task parameters
- Long-running delegated tasks with progress updates

## Platform Constraints

Both platforms:

- Can read contacts with permission
- Can launch phone calls
- Can use camera and calendar with permission
- Have background execution limits

Android generally allows more flexibility for:

- deeper integrations
- background services
- call-related flows
- local model experimentation

iOS generally requires stricter patterns for:

- background activity
- call handling
- system-level integrations
