# Smartphone Migration Plan

## Keep

- `cloud_backend/`
- `desktop_app/`
- `shared/`
- memory and sync concepts
- adaptive interface concept

## Reframe

- `software/` becomes legacy edge runtime
- `hardware/` and `mechanical/` become future dedicated device path
- top-level product story becomes smartphone-first

## Add

- `mobile_app/` as the main prototype client
- mobile-native capability adapters
- future-facing agent gateway contracts
- confirmation and trust policy layer

## Delivery Phases

1. Documentation and architecture refactor
2. Mobile app scaffold
3. Contacts/call/calendar MVP
4. Camera/documents/memory polish
5. Agent workflow abstractions
6. Future dedicated thin-client convergence
