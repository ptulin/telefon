# Mobile App

This is the smartphone-first client scaffold for the Personal AI Phone prototype.

## Stack

- Expo
- React Native
- TypeScript

## Design Goals

- one large, simple AI interface
- easy mode switching without forcing app-hunting
- voice-first interaction path
- future expansion into contacts, calling, calendar, camera, documents, and agent workflows

## MVP Direction

1. Connect to `cloud_backend/`
2. Add contacts access and call initiation
3. Add calendar access and event creation
4. Add camera and document flows
5. Add offline cache and sync queue

## Run

```bash
npm install
npm run start
```
